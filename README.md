# Gaokao Diagnostic Coach

一个面向中国高考备考的 Agent Skill。它不是通用搜题器，而是根据省份、目标卷、成绩、错题和学生反馈，逐层定位学科、板块、考点、题型与错因，再生成按提分价值排序的解决方案。

## 初版功能

- 覆盖语文、数学、英语、物理、化学、生物、思想政治、历史和地理；
- 区分传统全国卷、新高考/新课标卷、自主命题卷和地方选考卷；
- 对 2017–2026 年真题给出年份与卷种可比性权重；
- 区分知识、方法、信息提取、推理建模、运算表达、规范和时间等错因；
- 输出 S/A/B/C 优先级、训练路径、达标标准和复测入口；
- 提供可选的优先级计算脚本。

## 使用

安装后可以这样提问：

```text
使用 $gaokao-diagnostic-coach 帮我诊断。
我是广东 2027 届考生，选物化生。
近三次数学是 92、105、98 分，目标 125 分，每天可用 50 分钟。
我感觉函数和解析几何有问题，但不确定具体原因。请先问我必要的问题。
```

学生不知道薄弱板块时，可以直接说“请先帮我定位”。Skill 会每轮询问 3–5 个会改变结论的问题，而不是一次抛出长问卷。

## 安装

支持 Agent Skills 结构的工具可将 `gaokao-diagnostic-coach/` 目录复制到其 Skills 目录。在 Codex 中可使用 Skill Installer 从本仓库的 `gaokao-diagnostic-coach` 路径安装。

`agents/openai.yaml` 是 Codex/OpenAI 的可选界面元数据；其他平台不识别时可忽略，核心指令位于 `SKILL.md`。

## 图像与试卷

本 Skill 本身不提供视觉、OCR 或 PDF 解析能力。是否能读取试卷照片和手写作答，取决于宿主平台、模型与已连接工具。不支持图像时，用户可提供题号、题目摘要、作答、参考答案和得分。

## 数据边界

初版已建立九科诊断图谱、证据等级和近十年权重规则，但没有声称已逐题人工校验全国所有高考卷。第三方试卷索引只作为来源线索，未核验答案不作为权威评分标准。详见 `references/sources-and-coverage.md`。
