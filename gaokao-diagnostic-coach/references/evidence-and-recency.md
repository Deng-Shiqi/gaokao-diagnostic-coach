# 证据、年份与卷种权重

## 初版时间窗口

“近十年”指 2017–2026。不把十年内所有试题视为同等可比，因为课标、卷种和高考综合改革会改变题型与内容范围。

| 年份 | 时间权重 | 默认用途 |
|---|---:|---|
| 2026 | 1.00 | 当前最新形式与能力要求 |
| 2025 | 0.92 | 当前卷种结构与改革后特征 |
| 2024 | 0.84 | 近期稳定性核对 |
| 2023 | 0.74 | 近期多年比较 |
| 2022 | 0.65 | 新高考过渡期比较 |
| 2021 | 0.57 | 新旧卷种对照 |
| 2020 | 0.48 | 新高考卷出现时的结构参考 |
| 2019 | 0.40 | 长期主干与旧高考对照 |
| 2018 | 0.34 | 长期主干校验 |
| 2017 | 0.29 | 长期主干校验 |

这是默认值，不是统计学结论。如果目标卷仍使用与旧卷高度一致的结构，可提高相应年份权重。

## 卷种可比性系数

| 与目标考试的关系 | 系数 |
|---|---:|
| 同卷种、同课标、相邻年份 | 1.00 |
| 同课标、同统考科目、不同全国卷 | 0.80 |
| 同省选考科目、相同命题机构 | 0.90 |
| 他省选考卷但课标与结构接近 | 0.60 |
| 改革前旧卷或考查范围明显不同 | 0.35–0.50 |

未确认省份、年份或卷种时，不给出精确频率或“必备题型”结论。

## 证据等级

| 等级 | 条件 | 可如何表达 |
|---|---|---|
| A | 课标、官方考试文件或教育部考试院明确评析 | “官方明确强调……” |
| B | 同卷种近 3 年或多卷稳定重复，且与课标一致 | “近年稳定出现/持续重视……” |
| C | 单年、单卷或第三方未完全核验数据 | “可作训练参考，不能推断下年……” |

## 优先级不等于频率

高频但学生已稳定掌握的板块，不应占用最多时间。低频但属于前置知识、且正在阻断多个主干题型的内容，可以被提高优先级。
